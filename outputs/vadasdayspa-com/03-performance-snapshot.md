## Where they stand

- **Brand search is healthy.** A search for "Vada's Day Spa East Lansing" returns the
  official site first, followed by Yelp, Facebook, Instagram, ClassPass, and directory
  listings — the brand owns its own results page.
- **Strong visibility on "day spa" queries.** vadasdayspa.com appears at or near the
  top of results for "day spa East Lansing MI", "best day spa Lansing Michigan", and
  "spa day packages Lansing MI" — the last one surfacing both the homepage and the
  dedicated /spa-day-packages page. Package intent, the client's stated priority, is
  already the strongest visible asset.
- **Weak visibility on "massage" queries.** Vada's did not appear in the visible top
  results for "massage East Lansing MI"; that query is held by massage-specialist
  businesses (Massage & Wellness, Creative Wellness, Patient Relaxation). Massage is a
  core service, so this is the clearest visible gap.
- **Review footprint is fragmented and thin on the platforms that matter most.** The
  strongest count is a Birdeye aggregate (4.6 stars, 128 reviews); Yelp shows only 12
  reviews. A native Google review count was not visible in search results this run and
  needs to be confirmed from the GBP dashboard.
- **One-line verdict:** solid visible presence for "day spa" and package searches in a
  market where the largest independent competitor (Zoë Life) has roughly 2.7x the
  reviews at a higher rating; the visible gaps are massage-query presence and review
  volume/rating on Google.

## Measurement plan — what to provide before the next run

Providing any one of these upgrades the snapshot; all three make it complete.

**1. DataForSEO credentials (fastest, no client involvement needed)**
- Set `DATAFORSEO_USERNAME` and `DATAFORSEO_PASSWORD` in the environment (per
  `.mcp.json`) and confirm the DataForSEO MCP connects.
- The next run will then pull: domain rank overview (keyword count, estimated traffic,
  position buckets, traffic value) for vadasdayspa.com + all competitors, the full
  ranked-keyword list with striking-distance filter, and the 6–12 month historical
  trend. Location code: United States (2840), language: English ("en").

**2. Google Search Console export (real query data, needs owner access)**
- In GSC, verify/choose the property for vadasdayspa.com (domain property preferred).
- Performance > Search results > set date range to **last 12 months** > Export >
  Google Sheets or CSV — export the **Queries** and **Pages** tabs.
- Repeat with **last 3 months** for a recent view. Drop the files in
  `outputs/vadasdayspa-com/data/` (create the folder) as `gsc-queries-12mo.csv`,
  `gsc-pages-12mo.csv`, `gsc-queries-3mo.csv`.
- This gives true impressions, clicks, and average positions — better than any
  third-party estimate for a site this size.

**3. GA4 export (what visits turn into)**
- In GA4: Reports > Acquisition > Traffic acquisition, date range last 12 months,
  export CSV as `ga4-traffic-12mo.csv` to the same data folder.
- If booking or call events exist, also export Engagement > Events. If they do not
  exist, that is itself a finding — booking conversions should be tracked before
  progress can be claimed.

**Also confirm from the GBP dashboard (2 minutes):** native Google review count and
rating, and the primary category (should be "Day spa", not "Nail salon"). Optionally
connect the GBP in Windsor.ai for the Local SEO Manager.
